# Build a Premium Fictional Casino Simulation App

You are building a polished, production-grade fictional casino simulation application designed to feel like a real native product on both **iPhone/iPad and macOS**.

This is a **virtual entertainment and simulation app only**.

There must be:

* No real-money gambling
* No deposits
* No withdrawals
* No cash-out
* No cryptocurrency
* No prizes with monetary value
* No payment processing
* No mechanism that converts virtual credits into real-world value

All currency in the application is fictional and exists only for gameplay.

The product should feel sophisticated, immersive, tactile, and premium rather than like a simple gambling website.

---

# 1. PRODUCT VISION

Create a fictional casino environment where users receive virtual credits and can spend those credits inside several simulated casino-style games.

The application should eventually contain games such as:

* Roulette
* Blackjack
* Slots
* Dice
* Coin Flip
* Crash
* Mines
* Plinko
* Wheel
* Hi-Lo

However:

## DO NOT BUILD ALL OF THESE AT ONCE.

The entire project must be developed incrementally.

The application must always remain runnable and usable after every milestone.

A future feature may exist in the architecture conceptually, but it must NOT be implemented until its milestone is explicitly activated.

This is the most important instruction in this entire specification.

## BUILD ONE MILESTONE AT A TIME.

Never implement multiple future milestones in one pass.

# 13. RANDOMNESS AND GAME LOGIC

Separate:

## Game logic

from:

## Rendering/UI

and:

## Randomness

A game should not calculate probability merely because an animation is currently playing.

Build deterministic, testable game engines.

Where practical:

* Allow seeded randomness in development/testing
* Keep probability configuration separate
* Make rules explicit
* Validate inputs
* Prevent impossible states
* Write unit tests for core game logic

The UI should display the result produced by the engine.

The UI must not secretly determine the result.
